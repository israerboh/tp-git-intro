# Mon mini-projet Git

## Objectif
Ce projet consiste à créer une page web simple pour apprendre à utiliser Git et GitHub.

## Technologies utilisées
- HTML
- CSS
- Git
- GitHub

## Comment ouvrir le projet ?
Ouvrir le fichier `index.html` avec un navigateur web.
